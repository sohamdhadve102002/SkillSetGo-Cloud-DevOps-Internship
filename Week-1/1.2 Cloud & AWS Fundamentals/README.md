# 1.2 Cloud & AWS Fundamentals

## 📌 Objective

The objective of this task is to understand the fundamentals of Cloud Computing and Amazon Web Services (AWS), with a focus on compute, storage, networking, security, monitoring, and basic cloud account management.

---

## ☁️ What is Cloud Computing?

Cloud computing provides on-demand access to computing resources such as:

- Compute
- Storage
- Networking
- Databases
- Security
- Monitoring

Cloud services allow users to provision and manage infrastructure without maintaining physical hardware.

---

## 🌐 Cloud Service Models

| Model | Description | Example |
|---|---|---|
| IaaS | Infrastructure as a Service | Amazon EC2 |
| PaaS | Platform as a Service | AWS Elastic Beanstalk |
| SaaS | Software as a Service | AWS services/applications |

---

## ☁️ Amazon Web Services (AWS)

Amazon Web Services (AWS) is a cloud computing platform that provides services for building, deploying, and managing applications and infrastructure.

For this exercise, I used **AWS** to study and practice fundamental cloud concepts.

---

## 🏗️ AWS Core Services Studied

### 1. Amazon EC2 — Compute

Amazon EC2 (Elastic Compute Cloud) provides resizable virtual servers in the AWS Cloud.

### Key Concepts

- EC2 Instances
- AMI
- Instance Types
- Key Pairs
- Security Groups
- Public and Private IP Addresses
- Regions
- Availability Zones

### Use Case

EC2 can be used to host websites, applications, and web servers.

---

### 2. Amazon S3 — Storage

Amazon S3 (Simple Storage Service) is an object storage service.

### Key Concepts

- S3 Buckets
- Objects
- Bucket Policies
- Object Permissions
- Storage Classes
- Versioning
- Static Website Hosting

### Use Case

S3 can be used to store files, images, backups, documents, and static websites.

---

### 3. Amazon VPC — Networking

Amazon VPC (Virtual Private Cloud) allows AWS resources to run inside an isolated virtual network.

### Key Concepts

- VPC
- Subnets
- Route Tables
- Internet Gateway
- Security Groups
- CIDR
- Public and Private Subnets

### Use Case

VPC is used to create and manage the networking environment for AWS resources.

---

### 4. AWS IAM — Security

AWS IAM (Identity and Access Management) controls access to AWS resources.

### Key Concepts

- IAM Users
- IAM Groups
- IAM Roles
- IAM Policies
- Permissions
- Least Privilege

### Use Case

IAM is used to securely manage authentication and authorization for AWS resources.

---

### 5. Amazon CloudWatch — Monitoring

Amazon CloudWatch is used to monitor AWS resources and applications.

### Key Concepts

- Metrics
- Logs
- Alarms
- Dashboards

### Use Case

CloudWatch helps monitor resource performance and create alerts.
