# Task 1.1 - Linux Administration

## Objective

To practice Linux file systems, permissions and process management.

## Environment

- OS: Ubuntu
- Platform: VirtualBox
- Shell: Bash

## 1. Basic Linux Commands

Commands practiced:

pwd - Displays the current working directory
ls - Lists files and directories
ls -la - Lists all files including hidden files with details
cd - Changes the current directory
mkdir -	Creates a new directory
touch	- Creates a new empty file
cp	- Copies files or directories
mv	- Moves or renames files
rm	- Removes files or directories
cat	- Displays file contents
clear	- Clears the terminal
history	- Displays previously executed commands

There are many more commands available, but it is not possible to explain all of them here. 
These are some of the most commonly used and important commands for basic usage.
